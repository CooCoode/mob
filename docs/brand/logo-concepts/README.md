# mob 卡通 Logo 候选方案

**已选定：01 Screen Buddy（屏幕小搭档）。** 正式 SVG、macOS 图标及生成说明见 [品牌资源](../README.md)。本目录保留最初的三方案设计稿和静态对比图。

以 mob 的三个核心能力为出发点：查看远程桌面、让 AI 操作电脑并执行任务、从不同设备连接办公室。保留现有界面的紫色基调，用奶白、薄荷绿和圆润的轮廓增加亲近感。

打开 [对比页面](index.html) 可查看三套方案、Dock 示意、32px 缩略图及深色背景效果；[静态对比图](preview.png) 可直接分享。

推荐 **01 屏幕小搭档**：无需解释就能看出电脑、助手和操作能力，适合首次接触 mob 的用户。02 的角色性更强，可延展出工作中、等待批准、任务完成等表情。03 更有远程陪伴感，窗口造型也兼顾手机与桌面入口的联想。

## 设计与文件

- 按用户选择直接绘制 SVG，未调用图片生成 API；SVG 由路径和基础几何图形组成，可继续编辑。
- SVG 画布为 `512 × 512`，背景透明，不依赖外部图片或字体。PNG 是同一 SVG 的 `1024 × 1024` 透明背景导出。
- 对比页中的 `mob` 文字、英文短句、圆角图标底板属于展示排版，不包含在独立 Logo 文件中。
- 主色：紫色 `#6559E8` / `#8B85FF`；描边 `#282347`；奶白 `#F9F4E9`；薄荷绿 `#B8ECCC`。
- 候选方案保存在本目录；Screen Buddy 已生成正式 `.icns` 和各尺寸资源，并接入 Tauri 及应用界面。
- 已在浏览器检查 SVG 加载、浅色及深色背景，以及桌面/窄屏对比页。正式使用前仍需检查真实 Dock 和菜单栏尺寸；未进行商标相似性检索。

## 复现设计方向

共同要求：原创卡通角色、轮廓简洁、圆角粗描边、紫色品牌基调、透明底、主体居中，独立 Logo 不含文字。

1. **屏幕小搭档**：将电脑屏幕设计成助手的脸，奶白外壳、紫色屏幕、简短笑脸和小脚，用薄荷绿鼠标指针表达操作能力。
2. **多手小章鱼**：紫色圆润章鱼，卷曲触手分别拿着完成任务的卡片和鼠标指针，表情活泼，表达工具协作。
3. **传送门小精灵**：薄荷色精灵从紫色电脑窗口里探出，尾巴变为向外的指针，表达人与远程电脑之间的连接。
